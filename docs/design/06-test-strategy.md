## 2. ゴールデンテスト（PCI）

- 場所: `apps/api/tests/unit/domain/pace/test_pci_golden.py`
- 手検証済みの (走破タイム, 上がり3F, 距離) → PCI を固定
- 式変更時は**必ず更新**し、変更根拠をコミットメッセージに記載（ADR-0004）

---

## 3. プロパティテスト（hypothesis）— 不変条件

PCI:
- 均等ペース（前半1F = 上がり1F）→ PCI ≈ 50
- 上がりが相対的に速いほど PCI 高（スロー方向）
- 距離が変わっても均等ペース条件では PCI ≈ 50

脚質:
- 全走1番手 → 逃げ
- 番手率が閾値未満に分散 → 自在

PAI:
- 0〜100 の範囲を逸脱しない
- 各減点が0なら PAI = 100

---

## 4. 想定RPCI の受入検証（C4）

検証ハーネス（バックテスト）で過去5年データに対し計測:

| 指標 | 目標 |
|---|---|
| MAE（想定RPCI vs 実績RPCI） | ≤ 1.5 |
| 展開3分類（スロー/平均/ハイ）一致率 | ≥ 60% |

- ベースライン（過去同条件の単純平均）と比較し改善を確認
- モデル更新時は `model_version` ごとに指標を記録

---

## 5. TARGET 差分検証（Should）

- TARGET 表示値（許諾範囲のサンプル）と自社 PCI/RPCI を突合
- 完全一致は目標とせず、差分傾向の把握と独自補正導入の判断材料とする（ADR-0004）
