# ユビキタス言語（Ubiquitous Language）

本プロジェクトのドメイン用語を統一定義する。コード・ドキュメント・会話で必ずこの語彙を使う。

---

## ペース指標

### PCI (Pace Change Index / ペースチェンジ指数)
個馬の1走における前半／後半のペース比率指数。

- **> 50**: スロー（後半が相対的に速い／前半が緩い）
- **= 50**: イーブン（均等ペース）
- **< 50**: ハイ（前傾ラップ／前半が速い）

計算式の唯一の真実の場所: `apps/api/src/pci/domain/pace/pci.py`（ADR-0004）。
方向性は固定だが係数は `formula_version` で管理。

### RPCI (Race PCI / レースペース指数)
レース全体のペースを表す指数。

- **実績RPCI**: レース確定後に算出される実際のペース指数
- **想定RPCI**: 出走馬の脚質構成・距離・コース・馬場から予測したペース指数。**本プロダクトの中核**（ADR-0005）

### PCI3
上位3着馬の PCI 平均。レースの代表ペース指標。公開されている定義に従う。

---

## 脚質（Running Style）

過去5走の**4角通過順位**から算出する馬のレース運びの分類。

| 脚質 | 暫定判定ルール（MVP） |
|---|---|
| **逃げ** | 1〜2番手率が 60% 以上 |
| **先行** | 3〜5番手率が 60% 以上 |
| **差し** | 6〜9番手率が 60% 以上 |
| **追込** | 10番手以降率が 60% 以上 |
| **自在** | 上記いずれにも該当しない |

- 閾値は設定ファイルで変更可能（将来最適化前提）
- 実装の隔離場所: `apps/api/src/pci/domain/pace/running_style.py`

---

## 適性・展開

### PAI (Pace Adaptability Index / ペース適性指数)
想定RPCI への馬の適性を表す**プロダクト独自指標**（0〜100、高いほど展開合致）。

MVP暫定定義（ADR-0005 / 設定で重み変更可）:
```
PAI = 100 − RPCI差補正 − 距離補正 − 馬場補正
```
- 各減点は `reason` として出力する（説明可能性）
- 正式定義は実運用で検証しながら決定

### 展開合致馬
PAI が高く、想定ペースで恩恵を受けると判定された馬。

### 展開シナリオ
想定RPCI に基づくレース展開の予測（ハイ／平均／スロー、隊列イメージ、先行争いの想定等）。

## レースデータ用語

| 用語 | 定義 |
|---|---|
| **上がり3F** | ゴール前3ハロン（600m）の走破タイム（秒） |
| **通過順位** | 各コーナー通過時点での順位（1〜4角） |
| **走破タイム** | レースの全体走破タイム（秒） |
| **斤量** | 騎手＋装具の負担重量（kg） |
| **馬場状態** | 良／稍重／重／不良 |
| **血統登録番号 (ketto_num)** | 競走馬の一意識別子 |

---

## 識別子

### RaceKey
レース識別子（16桁）。

```
年(4) + 月日(4) + 競馬場コード(2) + 回(2) + 日目(2) + R(2)
例: 2026 0614 06 03 08 11
```

---

## データ層（ADR-0006）

| 用語 | 定義 |
|---|---|
| **raw層** | JV-Link からの原文データ。追記のみ・改変禁止 |
| **core層** | 正規化済みドメインデータ（races, race_entries 等） |
| **mart層** | 分析結果（predicted_pace, pace_fit 等）。version 付き・再計算可能 |

## バージョン

| 用語 | 定義 | 例 |
|---|---|---|
| **formula_version** | PCI 計算式のバージョン | `"pci-v1"` |
| **model_version** | 予測モデルのバージョン | `"rule-v1"`, `"lgbm-v2"` |

## JV-Link レコード種別（MVP取り込み対象）

| 種別 | 内容 |
|---|---|
| **RA** | レース詳細（距離・コース・馬場・ラップ等） |
| **SE** | 馬毎レース情報（成績・通過順位・上がり3F等） |
| **UM** | 競走馬マスタ |
| **KS** | 騎手マスタ |
| **CH** | 調教師マスタ |
